# 냐냐의 스페인어 공부방

단어장 · 문법 노트 · 퀴즈 · 복습(망각곡선) · AI 첨삭이 들어 있는 언어 학습 앱입니다.
설치도 빌드도 없습니다. HTML 파일 하나와 JS 몇 개가 전부입니다.

---

## 1. PC에서 바로 쓰기

압축을 풀고 **`index.html` 을 더블클릭**하면 끝입니다. 서버도 GitHub도 필요 없습니다.

데이터는 그 브라우저 안에만 저장됩니다. 그래서 크롬으로 쓰다가 엣지로 열면 빈 화면입니다.
기기·브라우저를 넘나들며 쓰려면 아래 **4번 동기화**를 하세요.

## 2. 폰에서 쓰기 (GitHub Pages · 무료)

폰 브라우저로는 내 컴퓨터의 파일을 열기 어려워서, 인터넷 주소를 하나 만들어야 합니다.

1. [github.com](https://github.com) 가입
2. 오른쪽 위 `+` → **New repository** → 이름 아무거나 (예: `my-vocab`) → **Public** → Create
3. **Add file → Upload files** → 압축 푼 폴더의 **내용물**을 드래그
   (폴더째가 아니라 `index.html`, `css`, `js` 가 보이게) → 아래 **Commit changes**
4. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → **Save**
5. 1~2분 뒤 주소가 생깁니다: `https://아이디.github.io/my-vocab/`
6. 폰에서 그 주소를 열고 → 브라우저 메뉴 → **홈 화면에 추가** → 앱 아이콘처럼 씁니다

> Public 저장소라 코드는 누구나 볼 수 있습니다. 다만 **API 키와 비밀번호는 코드에 들어 있지 않으니**
> 새어 나갈 것은 없습니다. 둘 다 각자 브라우저에만 저장됩니다.

## 3. AI 기능 켜기 (Gemini API 키)

AI 첨삭·단어 자동완성·주관식 채점은 Google Gemini 를 씁니다.

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서 키 발급 (무료 등급 있음)
2. 앱 우측 상단 배지를 눌러 키 입력

**키는 기기마다 따로 넣어야 합니다.** 동기화 대상이 아니라서 PC에 넣어도 폰에는 안 넘어갑니다.
키가 없어도 단어장·퀴즈·복습은 그대로 돌아갑니다 (AI 기능만 빠짐).

## 4. 기기 간 동기화 (Firebase) — PC랑 폰을 같이 쓰려면

### 4-1. 내 데이터베이스 만들기

1. [console.firebase.google.com](https://console.firebase.google.com) → 프로젝트 만들기
2. 왼쪽 메뉴 **Realtime Database** → 데이터베이스 만들기 → 위치는 아무거나 → **테스트 모드**로 시작
3. 위에 보이는 주소를 복사 — `https://○○○-default-rtdb.firebaseio.com`

### 4-2. 앱에 넣기

앱의 **동기화 설정 → 고급 → 저장소 주소** 에 위 주소를 넣고, 비밀번호를 정합니다.
**PC와 폰에 똑같은 주소·비밀번호**를 넣어야 데이터가 오갑니다.

> ⚠️ **저장소 주소는 반드시 자기 것으로 바꾸세요.**
> 안 바꾸면 기본값(원래 만든 사람의 데이터베이스)에 내 단어가 쌓입니다.
> 비밀번호가 다르면 서로 섞이지는 않지만, 남의 창고를 쓰는 셈입니다.

### 4-3. 30일 뒤 잠기지 않게 하기 ★

테스트 모드는 **30일 뒤 자동으로 막힙니다.** 그 전에 규칙을 바꿔야 계속 쓸 수 있습니다.

Firebase 콘솔 → **Realtime Database → 규칙(Rules)** 탭 → 아래 내용으로 통째로 바꾸고 **게시**:

```json
{
  "rules": {
    "vocab": {
      "$password": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

이 규칙이 하는 일:

- 이 앱은 데이터를 `/vocab/<비밀번호>` 경로에 넣습니다. **비밀번호가 곧 내 데이터가 있는 자리**입니다
- 위 규칙은 그 자리를 정확히 아는 사람만 읽고 쓰게 합니다
- 부모 경로(`/vocab`)에는 권한을 주지 않았으므로, **남이 목록을 훑어볼 수는 없습니다**
- 만료일이 없어서 30일 뒤에도 그대로 돌아갑니다

> 🔑 **비밀번호는 길게 잡으세요.** 이 방식은 "주소를 모르면 못 본다"에 기대는 것이라,
> `1234` 같은 짧은 숫자는 찍어서 맞힐 수 있습니다. 영문·숫자 섞어 12자 이상을 권합니다.
> 잊어버리면 그 데이터를 다시 찾을 길이 없으니 어딘가에 적어두세요.

동기화를 안 해도 앱은 잘 돌아갑니다. 그때는 데이터가 그 브라우저에만 남습니다.
**백업 · 복원** 메뉴에서 파일로 내보내 두는 것도 방법입니다.

## 다른 언어로 쓰려면

**이 앱은 스페인어 전용으로 짜여 있습니다.** 설정으로 언어를 바꾸는 구조가 아닙니다.

그대로 쓸 수 있는 것 — 단어장, 문법 노트(표 편집기), 퀴즈, 망각곡선 복습, 쓰기 연습,
학습 일지, 게임, 알 키우기.

손봐야 하는 것:

| 무엇 | 어디 |
|---|---|
| 동사 활용표 (현재/부정과거/현재분사, `e➡️ie` 같은 불규칙 분류) | `js/vocab.js` |
| 관사 el/la 처리, 악센트·철자 채점 규칙 | `js/quiz.js` |
| AI 프롬프트 (전부 "스페인어" 전제) | `js/ai-feedback.js`, `js/vocab.js` |
| 기본 단어·문법 예시 | `js/dictionary-data.js`, `js/core.js` |

## 파일 구성

```
index.html              화면 전체 (탭·모달 구조)
css/style.css           노트 편집기 등 직접 쓴 스타일
js/core.js              저장·동기화·문법 노트·달력·공용 도구
js/vocab.js             단어장·단어 등록·쓰기 연습
js/quiz.js              퀴즈·주관식 채점
js/games.js             게임·오늘의 복습
js/ai-feedback.js       AI 번역 첨삭
js/flashcards.js        깜빡이 카드
js/creatures.js         알 키우기 도감
js/dictionary-data.js   기본 단어 · 토스트 · 효과음 · Gemini 호출
```

바깥에서 가져다 쓰는 것은 Tailwind CSS 와 Font Awesome (CDN) 뿐입니다. 그래서 인터넷은 필요합니다.
